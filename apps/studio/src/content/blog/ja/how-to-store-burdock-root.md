ゴボウを保存していたら、いつの間にか木のようにカチカチに硬くなったり筋っぽくなって困った経験はありませんか？🪵

ゴボウは切られたり水分が抜けて乾燥すると、自らを防御するために細胞壁にリグニン（Lignin）という成分を急速に蓄積し、まるで木材のように硬くなる木質化（Lignification）現象を起こします。また、カットした断面が空気中の酸素に触れるとポリフェノール酸化酵素（PPO）により黒く褐変します。そのため、土がついたまま水分を保持することが硬化を防ぐ鍵となります。

本記事では、農林水産省（MAFF）、USDA、食品医薬品安全処のガイドラインに基づき、ゴボウのシャキシャキ感と風味を長期間保つ3段階の科学的保存法をご紹介します。🛡️

## 2. 保存時の必須ルールと注意事項

<div class="my-6 p-5 md:p-6 rounded-r-2xl rounded-l-md border-l-4 border-amber-500/30 bg-amber-500/5 dark:bg-amber-500/10 bg-amber-500/[0.06] dark:bg-amber-500/10 border-amber-500/30 flex items-start gap-4 shadow-xs backdrop-blur-xs">
  <span class="text-xl md:text-2xl flex-shrink-0 mt-0.5">⚠️</span>
  <div class="flex-1 min-w-0">
    <strong class="text-slate-950 dark:text-white font-extrabold block text-base md:text-lg mb-1.5 tracking-tight">水分損失による木質化（Lignification）に注意してください 🪵</strong>
    <p class="text-slate-800 dark:text-slate-200 text-sm md:text-base m-0 leading-relaxed font-normal break-words">
      ゴボウが乾燥すると細胞壁にリグニン成分を急激に蓄積し、木のように硬く筋っぽく変化します。土を洗い流さず水分を保持することが木質化を防ぐポイントです。
    </p>
  </div>
</div>

<div class="my-6 p-5 md:p-6 rounded-r-2xl rounded-l-md border-l-4 border-amber-500/30 bg-amber-500/5 dark:bg-amber-500/10 bg-amber-500/[0.06] dark:bg-amber-500/10 border-amber-500/30 flex items-start gap-4 shadow-xs backdrop-blur-xs">
  <span class="text-xl md:text-2xl flex-shrink-0 mt-0.5">⚠️</span>
  <div class="flex-1 min-w-0">
    <strong class="text-slate-950 dark:text-white font-extrabold block text-base md:text-lg mb-1.5 tracking-tight">調理後の断面露出によるPPO褐変を防いでください 🧪</strong>
    <p class="text-slate-800 dark:text-slate-200 text-sm md:text-base m-0 leading-relaxed font-normal break-words">
      ゴボウの皮をむいたり切ったりするとポリフェノール酸化酵素（PPO）が活性化し、空気中の酸素と結合して急速に褐変します。薄く酢を入れた水（pH酸性化）に浸すことで酵素活性が抑えられ、アクも抜けます。
    </p>
  </div>
</div>
