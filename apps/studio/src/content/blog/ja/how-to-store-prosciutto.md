ワインのおつまみに高級な生ハム（プロシュートやハモン）を開封して食べた後、残りを冷蔵庫に入れておいたらカチカチに乾燥して変色してしまった経験はありませんか？🥓

プロシュートやハモンは長期間の塩蔵と乾燥を経て水分活性度（水分活性 (Aw) < 0.85）を低下させているため、有害細菌の増殖が抑えられた安定した加工肉です。しかし、不飽和脂肪酸を多く含むため、空気中の酸素に触れた瞬間から脂質自動酸化(Lipid Peroxidation)反応が始まります。これによりミオグロビンが酸化して褐変を起こし、戻り臭（酸化臭）や硬化が発生します。

本記事では、食品安全の専門家が推奨する生ハムの品質を保つ3段階の科学的保存法をご紹介します。🛡️

## 2. 保存時の必須ルールと注意事項

<div class="my-6 p-5 md:p-6 rounded-r-2xl rounded-l-md border-l-4 border-amber-500/30 bg-amber-500/5 dark:bg-amber-500/10 bg-amber-500/[0.06] dark:bg-amber-500/10 border-amber-500/30 flex items-start gap-4 shadow-xs backdrop-blur-xs">
  <span class="text-xl md:text-2xl flex-shrink-0 mt-0.5">⚠️</span>
  <div class="flex-1 min-w-0">
    <strong class="text-slate-950 dark:text-white font-extrabold block text-base md:text-lg mb-1.5 tracking-tight">空気（酸素）に触れたまま常温や冷蔵室に放置しないでください ⚠️</strong>
    <p class="text-slate-800 dark:text-slate-200 text-sm md:text-base m-0 leading-relaxed font-normal break-words">
      不飽和脂肪酸の酸化とミオグロビンの変性が起こり、色が黄色っぽく変色して酸化臭が発生します。密閉しないと水分が抜けてゴムのように硬くなります。
    </p>
  </div>
</div>

<div class="my-6 p-5 md:p-6 rounded-r-2xl rounded-l-md border-l-4 border-amber-500/30 bg-amber-500/5 dark:bg-amber-500/10 bg-amber-500/[0.06] dark:bg-amber-500/10 border-amber-500/30 flex items-start gap-4 shadow-xs backdrop-blur-xs">
  <span class="text-xl md:text-2xl flex-shrink-0 mt-0.5">⚠️</span>
  <div class="flex-1 min-w-0">
    <strong class="text-slate-950 dark:text-white font-extrabold block text-base md:text-lg mb-1.5 tracking-tight">絶対に冷凍保管したり過度に低い温度に置かないでください ❄️</strong>
    <p class="text-slate-800 dark:text-slate-200 text-sm md:text-base m-0 leading-relaxed font-normal break-words">
      生ハムを冷凍すると独自の不飽和脂肪酸の結晶構造が破壊され、解凍時に脂肪とタンパク質の層が分離して、特有の柔らかい食感と風味が完全に損なわれます。
    </p>
  </div>
</div>
