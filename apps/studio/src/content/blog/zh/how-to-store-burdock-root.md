保存牛蒡时，您是否遇到过牛蒡干瘪变得像木头一样坚硬且多纤难嚼的情况？🪵

当牛蒡切开或失水干燥时，为了自我保护，其细胞壁会大量积聚木质素（Lignin），发生类似木头般变硬的木质化（Lignification）现象。此外，切面暴露于空气中时，多酚氧化酶（PPO）会导致其迅速褐变。因此，在不洗去泥土的状态下保持水分是防止牛蒡变硬的关键。

本指南基于日本MAFF、USDA及韩国MFDS的权威指南，为您带来3步科学保存秘诀，帮您长久锁定牛蒡的清脆口感与营养。🛡️

## 2. 储存必需规则及注意事项

<div class="my-6 p-5 md:p-6 rounded-r-2xl rounded-l-md border-l-4 border-amber-500/30 bg-amber-500/5 dark:bg-amber-500/10 bg-amber-500/[0.06] dark:bg-amber-500/10 border-amber-500/30 flex items-start gap-4 shadow-xs backdrop-blur-xs">
  <span class="text-xl md:text-2xl flex-shrink-0 mt-0.5">⚠️</span>
  <div class="flex-1 min-w-0">
    <strong class="text-slate-950 dark:text-white font-extrabold block text-base md:text-lg mb-1.5 tracking-tight">严防失水导致的木质化（Lignification）变硬 🪵</strong>
    <p class="text-slate-800 dark:text-slate-200 text-sm md:text-base m-0 leading-relaxed font-normal break-words">
      牛蒡失水干燥后，细胞壁会快速沉积结构性木质素（Lignin），使其变得如木头般坚硬干柴。保留泥土不洗并锁住水分是防止木质化的核心。
    </p>
  </div>
</div>

<div class="my-6 p-5 md:p-6 rounded-r-2xl rounded-l-md border-l-4 border-amber-500/30 bg-amber-500/5 dark:bg-amber-500/10 bg-amber-500/[0.06] dark:bg-amber-500/10 border-amber-500/30 flex items-start gap-4 shadow-xs backdrop-blur-xs">
  <span class="text-xl md:text-2xl flex-shrink-0 mt-0.5">⚠️</span>
  <div class="flex-1 min-w-0">
    <strong class="text-slate-950 dark:text-white font-extrabold block text-base md:text-lg mb-1.5 tracking-tight">切块后使用稀释醋水抑制PPO酶促褐变 🧪</strong>
    <p class="text-slate-800 dark:text-slate-200 text-sm md:text-base m-0 leading-relaxed font-normal break-words">
      削皮或切块会激活牛蒡中的多酚氧化酶（PPO），接触空气迅速变黑。浸泡在稀释醋水（降低pH值）中可抑制酶活性并去除涩味。
    </p>
  </div>
</div>
