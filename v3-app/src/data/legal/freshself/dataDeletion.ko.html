! FreshSelf Data Policy (데이터 삭제 및 완전 소각 안내)

FreshSelf(프레시셀프) 앱은 사용자의 프라이버시를 존중하며 100% 로컬 오프라인 방식으로 구동됩니다. 사용자가 등록한 식재료 정보 및 이미지 등은 당사 원격 서버에 전혀 전송 및 저장되지 않고 사용자의 기기 내부에만 귀속됩니다. 따라서 웹을 통한 수동 데이터 삭제 요청은 불필요하며 존재하지 않습니다.

방법 A: 앱 내에서 완전 초기화 및 소각

앱 내부의 [설정] 화면에서 '앱 데이터 완전 초기화' 기능을 실행하면 기기 내부 SQLite 데이터베이스의 전 테이블 레코드와 로컬 WEBP 이미지 샌드박스가 즉시 완전 물리 삭제(소각)됩니다.

방법 B: 애플리케이션 직접 삭제 (언인스톨)

휴대폰 기기에서 애플리케이션을 직접 삭제(언인스톨)하시면, 모바일 OS 규격에 의해 기기 내 저장되어 있던 앱 샌드박스의 모든 로컬 정보와 데이터베이스가 즉시 영구 파기됩니다.

기기 내 삭제 및 소각 대상 데이터

  • 기기 내부 SQLite 데이터베이스 내 보관소(Space) 정보
  • 기기 내부 SQLite 데이터베이스 내 등록한 식재료(Item) 명세
  • 식재료 소비/폐기 기록 및 이력 데이터
  • 기기 로컬 샌드박스에 압축 보존되던 WEBP 이미지 일체

원격 서버 정보 미보관 안내

본 애플리케이션은 100% 독립 기동되므로 당사 원격 데이터베이스에는 식별 가능한 귀하의 프로필이나 인벤토리 정보가 일절 수집 또는 보관되지 않습니다. 문의 사항이 있으신 경우 언제든지 support@selalink.net 으로 이메일을 보내 주시기 바랍니다.
